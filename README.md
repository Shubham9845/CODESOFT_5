# 📇 Contact Management System (GUI)

A desktop-based Contact Management System built using **Python Tkinter** that allows users to manage contacts efficiently.

## 🚀 Features
- Add new contacts (name, phone, email, address)
- Search contacts by name or phone
- Update existing contact details
- Delete contacts
- Simple and user-friendly GUI

## 🛠️ Technologies Used
- Python
- Tkinter (GUI)

## ▶️ How to Run
1. Install Python
2. Clone the repository:
   git clone https://github.com/Shubham9845/contact-management-system.git

3. Run the program:
   python contact_manager.py
